# Drums

An endless drum ensemble for dancing, generated in the browser: https://nydrath.github.io/drums/

Static files only; the page sends nothing anywhere. Sources and licenses of the sounds and rhythms
are in [credits.html](credits.html). The drum sounds (`kit/kit.ogg`) are adapted from the circAfrique v4
drumkit by Jim Harney and shared under CC BY-SA 3.0; all other rights reserved.
